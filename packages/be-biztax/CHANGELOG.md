# Changelog

## 0.4.1

- A return names its entry point by file name, `be-tax-inc-rcorp-2026-04-30.xsd`, as FPS Finance's packages lay it out (one flat folder). It named it `be-tax-2026-04-30/DTS/…`, a folder that exists in no package, and Biztax refused the upload: "la référence href n'est pas correcte". `TaxonomyModule.schemaRef` is that file name.
- `parseBiztaxFile` finds the taxonomy by that file name, so a return written by an earlier version still reads.
- `scripts/arelle-check.sh` lays the taxonomy next to the instance, as the new reference needs.

## 0.4.0

- `@financica/be-biztax/taxonomies/ay2025-rcorp` and `ay2025-rle`: the `rcorp` and `rle` entry points of be-tax 2025-04-30 v1.0.2, for periods ending from 31 December 2024 to 30 December 2025. A 2024 company return with the mandatory chain of the 2025 sample, and a nil legal entities return, pass every formula assertion of the release in Arelle.

## 0.3.0

- `parseBiztaxFile`: a `.biztax` file read back into its returns, every fact with its form code, labels, period and dimensions, code lists decoded and the annexes apart. Throws `BiztaxParseError` on malformed XML or an unknown taxonomy.
- The taxonomy modules carry each concept's form `code` (`1872`, `1437.1`), the labels of every code (`CodeList.labels`) and of every explicit dimension member (`Dimension.memberLabels`).

## 0.2.0

- `@financica/be-biztax/taxonomies/ay2026-rle`: the `rle` entry point of be-tax 2026-04-30 v1.0.2, the legal entities tax return (IPM / RPB, form 276.5) of an ASBL, an AISBL or a foundation. A return with no line stated passes every formula assertion of the release in Arelle.
- The return names itself by entry point: rule `f-rle-2011` wants `IPM`, `RPB` or `StjP` where the company return wants `ISoc`, `VenB` or `GSt`. The `nrcorp` names are set from rule `f-nrcorp-2011`.

## 0.1.0

First release.

- `buildBiztaxReturn`, `validateBiztaxReturn`, `renderBiztaxReturn`: a resident corporate tax return (form 275.1) as the be-tax XBRL instance.
- `wrapBiztax`, `biztaxFileName`: the `.biztax` upload file, up to 25 returns.
- `@financica/be-biztax/taxonomies/ay2026-rcorp`: the `rcorp` entry point of be-tax 2026-04-30 v1.0.2, generated by `scripts/generate-taxonomy.ts`.
- `scripts/arelle-check.sh`: a rendered return against the official formula assertions, with Arelle.
