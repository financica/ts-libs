# Changelog

## 0.1.0

First release.

- `buildBiztaxReturn`, `validateBiztaxReturn`, `renderBiztaxReturn`: a resident corporate tax return (form 275.1) as the be-tax XBRL instance.
- `wrapBiztax`, `biztaxFileName`: the `.biztax` upload file, up to 25 returns.
- `@financica/be-biztax/taxonomies/ay2026-rcorp`: the `rcorp` entry point of be-tax 2026-04-30 v1.0.2, generated by `scripts/generate-taxonomy.ts`.
- `scripts/arelle-check.sh`: a rendered return against the official formula assertions, with Arelle.
